# Cryptex brand options

Per SPEC §18: dark graphite, enterprise, restrained accent. Wordmark set in system bold sans as placeholder; suggested fonts below.

## Option A — Cipher Ring
Two concentric cipher rings with tick marks; one notch aligned = vault unlocked.

- Palette: #0F172A, #1E293B, #2DD4BF, #94A3B8, #F8FAFC (accent #2DD4BF)
- Fonts: IBM Plex Sans / IBM Plex Mono

## Option B — Vault Cylinder
Side view of a cryptex: five rotating rings between end caps, the middle ring aligned.

- Palette: #1C1917, #292524, #F59E0B, #A8A29E, #FAFAF9 (accent #F59E0B)
- Fonts: Inter / JetBrains Mono

## Option C — Hex Lock
Hexagonal block (ledger) with a C-shaped cutout forming a keyway.

- Palette: #111827, #1F2937, #3B82F6, #9CA3AF, #F9FAFB (accent #3B82F6)
- Fonts: Space Grotesk / IBM Plex Mono

## Option D — Aligned Rings
Stacked offset ring bars that snap into alignment; abstract X from the offsets.

- Palette: #18181B, #27272A, #22C55E, #A1A1AA, #FAFAFA (accent #22C55E)
- Fonts: Manrope / Roboto Mono

## Option E — Keyhole Dial
Combination dial with a keyhole center and one highlighted index mark.

- Palette: #0B0F19, #1A1F2E, #A78BFA, #8B93A7, #F5F7FA (accent #A78BFA)
- Fonts: Sora / Fira Code
